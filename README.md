## BM、个人号、广告户：三个东西别买错

这是买 BM 之前必须想清楚的事。海外投放社区里被反复问到的那个问题——「我用个人号当 BM 管理员，个人号被封会不会失去 BM」——答案是会。原话很直接：主号挂了，BM 一起挂，除非你已经往 BM 里加了另一个管理员。

同一个讨论里还有一句更扎心的判断：只买 BM、却拿一个有风险的个人号去管，等于白买。

可行的做法是把身份拆开：

1. BM 的主管理员用一个干净、专门的个人号，不放日常社交、不做外联。
2. 你常用的那个号作为副管理员加进 BM，两个管理员同时存在。

**二解号和三解号到底差在哪？**

二解号是账号被限制广告功能后提交身份资料、第一次申诉成功，账号质量里显示绿标，也叫 956 号、验证 ID 号。三解号是在此基础上又被封一次、再次申诉成功，显示三行绿标，也叫 902 号。行业里的共识是两者在实际广告操作上差别不大，三解号贵出来的部分是「多一轮人工审核」带来的心理溢价。￥85 的二解号够用，￥120 的三解号买的是安心。

**3 天售后到底保什么？**

账号类商品售后期为购买日起 3 天，只对质量问题免费更换。邮箱类商品同样 3 天，点卡类没有售后，充值类到账后不再受理。账号售出即删档，买家自行保护账号安全，被盗无法找回。

**登录显示 180 天禁言为什么不赔？**

官方判定这是买家的环境和 IP 问题，不属于商品质量问题，明确不提供售后。号本身没被封，换个干净设备和网络环境通常能恢复。介意这一条的话，下单前就要想清楚。

**买的号会被原号主找回吗？**

正规平台售出后会删档，原号主理论上无法再登录。来路不明的号存在通过原邮箱找回的可能。拿到号后立刻改绑自己的邮箱、开启二步验证，是唯一能自己控制的防线。
